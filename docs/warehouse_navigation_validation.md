`z_sem=[16,512]`，候选为 `[1,9,1,30,2]`；离线保存时去掉 batch 维。真实生成的 `<REFLINE>` 最后 token 被实际处理。PREFILL 不更新 Route。离线跟随绑定是明确标记的协议夹具，真实跟踪验收见在线实验。

原 token 词表枚举约束的三个 TEXT 耗时为 6.979/9.429/4.551 秒。新的逐高分 token 语法检查、必要时完整词表回退，将对应耗时降到上表水平；三个生成原文逐字一致。此优化只针对 greedy、batch=1、无 beam，不以放宽语法获得加速。保存了两个版本的原文和逐项对照。

### 跟随丢失与恢复

`follow-geometry-04` 首帧人工 ROI `[430,315,530,720]` 建立绑定。场景人形在首次 TEXT 后 15–18 秒隐藏，跟踪丢失后控制停车。

对第 160 帧人工核验并提交 ROI `[455,368,504,524]`，回放了 46 条该源帧之后的真实检测，追到第 249 帧，保持原 binding ID。恢复后又完成 16 次 TEXT、6 次 PREFILL，发布 171 条非零前进命令。结果可从 `manual_binding_replay`、`person_track`、`snapshot_committed` 与 `executed-commands.jsonl` 交叉追溯。

这是单人短时关联与人工重确认；人形 USD 为平移模型，尚无步态动画，也没有验证多行人、长期身份保持或跟随精度。

### 模型为什么停车

所有最终实验的源帧诊断中，Flow 候选都超过速度限制；进入当前帧执行检查的候选也被拒绝。另外一部分结果在使用时已超过 500 ms 的 Flow 来源年龄限制。跟随模型实验在控制侧主要被来源年龄或目标丢失检查挡住，其源帧诊断同样是超速候选。

没有使用几何路线替换模型参考线或 Flow 候选，没有按 STOP-YIELD 标签直接判定安全。几何对照的移动不能用于证明未训练模型已经学会导航。
