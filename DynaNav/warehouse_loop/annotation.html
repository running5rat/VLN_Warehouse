回放补记事实（可选；只勾选当前源时刻确实已发生的事实）

应当停车：Route 使用 action=stop、status=active。已经到达且实际停稳：核验后补记相应事实，再使用 completed。仅单张静态截图不能证明车辆停稳，请结合历史图像和位姿／速度核验。












随“批准本时刻”保存，来源标记为人工回放核验；不会改写原始采集日志。历史事件显示在上方，后续帧无需重复勾选。这里记录一次事件的发生／首次确认，不是累计状态：同一次起步、路口或转弯，不要在以后每帧重复勾选。修改旧事实会使后续批准需要重新审核。





Route 填写示例（按实际进度选择，不会自动写入答案）

Route 必须是 JSON 对象，包含三个字段：remaining_instruction 写完整的剩余任务；current_subgoal 只写当前正在执行的一个子目标；status 写任务状态。不能只把一句指令放进大括号。


下面演示“走到通道尽头左转，然后前往灭火器旁停车”的不同阶段，不代表你的任务已经推进到这些阶段。如果原任务还有其他转弯或要求，必须保留尚未完成的部分。


① 尚未到通道尽头：当前子目标是前进，不是左转

{
  "remaining_instruction": "Proceed along the aisle, turn left at its end, then approach the fire extinguisher you see and stop.",
  "current_subgoal": {
    "action": "advance_to_corridor_end"
  },
  "status": "active"
}


② 已到通道尽头，正在左转

{
  "remaining_instruction": "Turn left, then approach the fire extinguisher you see and stop beside it.",
  "current_subgoal": {
    "action": "turn",
    "direction": "left"
  },
  "status": "active"
}


③ 左转已完成，已看到并确定要接近的灭火器

{
  "remaining_instruction": "Approach the visible fire extinguisher ahead and stop beside it.",
  "current_subgoal": {
    "action": "approach_landmark",
    "category": "fire extinguisher",
    "description": "The visible fire extinguisher ahead"
  },
  "status": "active"
}


若同时可见多个灭火器，description 应根据当前观测进一步区分；尚未看到时，不要照抄“前方可见”。


④ 已到达指定目标旁并实际停车，任务完成

{
  "remaining_instruction": "Reached the target fire extinguisher vicinity and stopped.",
  "current_subgoal": {
    "action": "stop"
  },
  "status": "completed"
}


只有已发生的到达、停车事实支持完成时才填写 completed。当前审批还要求记录 target_visible、stopped 和 arrival_confirmed 事件；可在上方回放补记区核验并记录；仅看见目标或发出停车命令不算完成。


状态：active 进行中；waiting 暂时等待；needs_clarification 指令或指代不清；completed 有证据支持的整项任务完成。下一时刻会读取本时刻批准的 Route；改写措辞不代表实际取得进展。




Route 动作协议
advance_to_intersection: ordinal；advance_to_corridor_end；turn: direction left/right；approach_landmark: target_text/category/description；relative_motion: direction、distance_m、origin=subgoal_start；explore；follow_person: description；wait；stop。status: active/waiting/needs_clarification/completed。




整段验收不要求固定转向次数或单独的 start 标记；请人工核对原始指令是否完成。仍须全部关键帧批准有效，并有目标可见、实际停车和到达事实。
